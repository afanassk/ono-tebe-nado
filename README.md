## 📖 Описание проекта

**«Оно тебе надо»** — это лендинг интернет-аукциона необычных вещей с историей. Сайт представляет собой одностраничный веб-ресурс, демонстрирующий актуальные лоты, категории товаров и информацию о самом аукционе.

### 📌 Цели и задачи проекта

- Создание семантической верстки сайта по макету Figma.
- Построение сложных и комбинированных раскладок (CSS Grid + Flexbox).
- Организация структуры стилей с соблюдением правил чистого кода и переиспользования блоков.
- Настройка графических слоев, кастомной типографики и фоновых элементов.

### 🛠️ Стек технологий

- **HTML5** (семантическая разметка, доступность)
- **CSS3** (Flexbox, CSS Grid, кастомная типографика)
- **БЭМ (BEM)** — методология структурирования и именования классов
- **Pixel Perfect** — для отладки верстки

## 💡 Выводы по результатам проекта

* **Переиспользование элементов:** Освоен принцип модульности — одинаковые блоки и классы (например, контактная информация и адрес в шапке и подвале) переиспользуются без дублирования кода.
* **Фиксированная композиция:** Страница имеет фиксированную ширину **1100px**, сцентрированную по оси.
* **Сетки и раскладка:** 
  * Шапка (`header`) и подвал (`footer`) построены с применением **CSS Grid** для точного выравнивания логотипа, меню и контактов.
  * Блок с карточками лотов реализован с помощью **Flexbox** для удобного управления потоком карточек.
  * Приобретен навык уверенного комбинирования CSS Grid и Flexbox в рамках одного проекта.
* **Работа с графикой:** 
  * Для карточек лотов и промо-блока применены фоновые изображения (`background-image`).
  * Поверх изображений добавлен затемняющий **overlay-слой** для обеспечения контрастности и читаемости текста.
* **Пиксельная точность:** Типографика, межбуквенные интервалы и отступы настроены вручную для точного соответствия макету Figma.

## ⚙️ Инструкция по развертыванию и системные требования

### Системные требования

Для запуска проекта достаточно любого современного браузера:

- Google Chrome / Яндекс Браузер
- Mozilla Firefox
- Apple Safari
- Microsoft Edge

### Инструкция по локальному запуску

1. Клонируйте репозиторий на свой ПК:

```bash
git clone git@github.com:afanassk/ono-tebe-nado.git
```

2. Перейдите в директорию проекта:

```bash
cd ono-tebe-nado
```

3. Откройте файл `index.html` в браузере.
